\# PreOrder 2.0 – Architecture



\## Purpose



The PreOrder system is a Laravel 12 + Filament based B2B preorder platform.



The system is developed using a modern workflow:



\- GitHub

\- Docker

\- Synology NAS Development Environment

\- Feature Branches

\- Development → Test → Production



\---



\## Main Modules



\- Authentication

\- Partner Portal

\- Administration (Filament)

\- Product Management

\- Price Lists

\- Orders

\- Imports / Exports

\- Catalogs

\- Permissions (v2)

\- Translation System (v2)



\---



\## Architecture Principles



\- Single Responsibility

\- Modular design

\- RBAC permission model

\- Unlimited language support

\- Docker based development

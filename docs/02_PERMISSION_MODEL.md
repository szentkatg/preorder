\# Permission Model (Planning)



\## Goal



Replace the current permission system with a flexible RBAC architecture.



\## Requirements



\- Multiple partners per user

\- Multiple addresses per user

\- Function permissions

\- Data permissions

\- Reusable roles

\- Future admin permissions

\- The permission system must also manage permissions for both the Filament Admin and the Partner Portal



\## Planned entities



\- Users

\- Roles

\- Permissions

\- User Roles

\- Role Permissions

\- Partner Assignments

\- Address Assignments
